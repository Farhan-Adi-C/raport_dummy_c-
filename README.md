<h1>Project Raport Siswa Kelas</h1>
1. Penjelasan Project  
Project ini digunakan untuk melakukan input nilai raport siswa per kelas dengan berbagai mata Pelajaran. Pada project ini, juga dilakukan penghitungan rata-rata dan perangkingan kelas. Setelah melakukan input seluruh siswa dan nilai tiap mata Pelajaran, akan ditampilkan seluruh siswa dan nilai per mata Pelajaran, disertai dengan rata-rata per siswa dan perangkingan kelas. Project ini menggunakan Bahasa pemrograman C++ untuk menjalankan program nya. 
2. Alur Project  
1.	Display awal (“Program Raport Siswa”) -> menggunakan cout  
2.	Input nama kelas -> menggunakan cin  
3.	Input jumlah siswa per kelas -> menggunakan cin  
4.	Input mapel-mapel -> menggunakan looping while  
5.	Kalau sudah selesai, input Boolean false , looping input mapel selesai -> tipe data boolean  
6.	Looping jumlah siswa -> menggunakan for  
7.	Pada looping, input nama siswa, dan looping mapel yang ada, kemudian masukan nilai mapel satu persatu -> disimpan pada array  
8.	Melakukan validasi nilai, nilai harus pada rentang 0 – 100 -> menggunakan if else  
9.	Jika looping siswa sudah selesai, melakukan perhitungan rata rata -> menggunakan function  
10.	Menentukan rangking siswa berdasarkan rata-rata -> menggunakan function   
11.	Menampilkan nama kelas,  seluruh data siswa, nilai per mapel, rata-rata, dan rangking siswa -> menggunakan for, cout
